## 二、分阶段改造清单

### P1 · 状态源解耦与守卫单一二进制化

**症结（实测校正）**：当前 **5 个** PowerShell 脚本（**1,210 行**，非方案所称 4 个 / 703 行），
强绑定 Windows PowerShell 5.1；`check-progress.ps1` 靠**正则**从 HTML 抠 SHA，**排版一改即失明**
（`GAP-025` 已修「加属性」这一类，**残余是「重构成 `<span>` 仍静默」**，已被自测 `A5` 钉住）。

- [ ] **1.1 引入结构化状态源 `.claude/state.json`（State 与 View 分离）**
  - **动作**：定义**机器唯一读写**的状态源 `.claude/state.json`（挡在 `.gitignore` 外）；
    **HTML 进度页降级为只读视图**——由脚本从 `state.json` + `record.md` **单向渲染**（遵守 D4：避免两处手改导致漂移）。
  - **⚠️ 关键设计约束（D4，不是可选项）**：**同一事实只能有一处权威源**。若 `state.json` 与 HTML 都手改，
    就重现了本项目反复记录的「两处副本必然先过期一份」。**故渲染必须是单向的，且页面顶部应声明"本页由脚本生成，勿手改"**。
  - **最小 Schema**：
    ```json
    {
      "schema_version": 1,
      "head_sha": "<7-40 hex>",
      "current_stage": "02-dev",
      "stage_assets": { "01-design": ["docs/adr/ADR-001.md"] },
      "three_hop_chain": { "qa-validator": "PASS", "falsifier": "PASS", "gate-auditor": "PENDING" },
      "updated_at_utc": "YYYY-MM-DDTHH:MM:SSZ"
    }
    ```
  - **解除条件对齐**：本条正是 `GAP-025` 台账里写的「**引入机器可读的结构化元数据块（与展示排版解耦）**」。

- [ ] **1.2 用编译型单文件 CLI（如 Go 的 `aicf-guard`）收拢 5 个 `.ps1`**
  - **动作**：把 `check-progress` / `check-numbers` / `inject-agents-tail` / `stop-adapter` / `self-test`
    收拢为**零外部依赖的跨平台 CLI**（子命令同名），原 `.ps1` 只留薄转发层。
  - **收益**：铲除 PS 5.1 的 `EAP` / `stderr` 污染 / `IsInputRedirected` 等宿主补丁；
    **自测耗时从 ~21 s 降到 <1 s**（**顺带解除 `DEFER-014`** 的「挂不挂 Stop」两难——挂上不再有代价）。
  - **解除条件对齐**：本条正是 `GAP-025` 台账里写的「**抽离跨平台守卫入口**」+ 用户待办 **#11**。

- [ ] **1.3 收紧 `GAP-002` 缺页静默判据**
  - **动作**：**只要仓库已存在 `record.md`**（代表工作区**已初始化运行**），若 `.claude/state.json` 或进度页缺失，
    **不再按「尚未初始化」静默 `exit 0`**，而是直接 `decision:block`。
  - **理由**：`GAP-002` 的已接受代价是「**缺页静默**与**尚未初始化**不可分」——
    而「`record.md` 存在」**正是那个可分的判据**。

### P2 · 拦截点前移至 `PreToolUse` 与代跑取证

**症结**：`Stop` 钩子属**事后**拦截；总控越权改代码、跨阶段漏硬资产、Antigravity 只读角色漏传参数、
以及总控「**假装代跑**」均缺乏**事前/事中**物理约束。

- [ ] **2.1 子代理租约锁 + 总控写代码物理拦截**（闭环 `GAP-024`）
  1. `.claude/settings.json` 与 `.agents/hooks.json` 挂 `PreToolUse` / `PostToolUse`。
  2. 派发业务角色（Claude Code 的 `Task` / Antigravity 的 `define_subagent`）时，
     `PreToolUse` 写租约文件 `.claude/active-role.lock`（活跃角色名 + 过期时间戳）；子代理返回时由 `PostToolUse` 销毁。
  3. 触发 `Write` / `Edit` 且路径属**业务代码目录**时，`PreToolUse` 查租约：**无活跃业务租约 ⇒ `decision:block`**
     （即"总控自己动手写代码"）。

- [ ] **2.2 跨环硬资产前置校验**（闭环 `GAP-017`）
  - **动作**：`PreToolUse` 拦写业务代码时读 `state.json` 的 `current_stage`；处于 `02-dev` 及之后，
    强制校验 `01-design` 的硬资产（`docs/adr/ADR-*.md` 等）**磁盘上真实存在且非空**；否则阻断并输出解除条件。

- [ ] **2.3 Antigravity 只读权限强校验**（闭环 `GAP-026` 前半）
  - **动作**：`.agents/hooks.json` 的 `PreToolUse` 拦 `define_subagent`，解析入参 JSON：
    目标角色为 `falsifier` / `gate-auditor` 时，**机械断言 `"enable_write_tools": false` 显式存在**；漏传或为 `true` 即阻断。

- [ ] **2.4 总控代跑物理证据链**（闭环 `GAP-005`）
  - **动作**：挂 **Shell 工具**（`Bash` / `PowerShell` / `run_command`）的 `PostToolUse`，
    **由宿主钩子进程自动**向 `.claude/exec-audit.jsonl` 追加**不可由模型伪造**的一行：
    ```json
    {"ts":"<UTC>","head":"<7-40 hex>","cmd":"<原文>","exit_code":0,"stdout_sha256":"<hex>","stdout_tail":"<尾>"
    }
    ```
  - **核验闭环**：`falsifier` / `gate-auditor` 判分时**用 `Read` 读该文件**核对 `cmd` / `head` / `exit_code`
    —— **彻底堵死"总控口头声称已代跑"**。
  - **⚠️ 前提（须先验证再动手）**：本条的**全部价值**在于「该行**由宿主进程**写、模型**写不了**」。
    **若模型也能写该文件，证据链即失效**——那就只是又一个"自证"。
    **判据**：注入一个「总控手写该行」的负向用例，**必须抓不到**（即模型确实写不了）才算成立。**该前提未验证。**

### P3 · 上下文按环路由 + Worktree 隔离

- [ ] **3.1 拆分 `AGENTS.md` 为「常驻内核 + 按环切片」**
  - **动作**：主文件压到 **< 10 KiB**（只留 D1–D4 · 角色注册制 · 任务定位协议 · 五段协议）；
    十环门禁细则拆入 `prompts/stages/stage-*.md`；`inject-agents-tail` 按 `state.json` 的 `current_stage` **动态注入**当前环与下一环。
  - **收益**：常驻体积砍 **≥50%**，**同时缓解 Antigravity 的 24,000 B 截断余量**。
  - **台账映射**：本条即 **`DEFER-008`（体量要不要继续拆）** —— 它是**待人工裁定**项，本路线图给出的是**做法**，**不是替裁定**。

- [ ] **3.2 单兵多开（`git worktree`）路径兼容**
  - **动作**：守卫路径解析统一用 `git rev-parse --show-toplevel` 定位**当前工作树**、
    `git rev-parse --git-common-dir` 定位**共享对象库**；
    确保并行开 2~3 个 worktree 跑不同 feature 时，`state.json` **互相隔离**、而 `check-numbers` 跨分支防撞车**全局生效**。
