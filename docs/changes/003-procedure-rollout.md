## 二、一个必须先说清的边界：**这不会减少常驻上下文**

`AGENTS.md` 是常驻的（`CLAUDE.md` 用 `@AGENTS.md` 导入）。而 `.claude/agents/*.md`
**本来就是按需加载的**——它们只在**派发该子代理时**进入那个子代理的上下文，总控侧只看到
`name` + `description`。

⇒ 对 `gate-auditor` / `falsifier` / `ssot-scribe` 加流程记忆，**常驻体积一点没减**。
真正的增量在**案例库**：把踩过的坑从「各角色文件里零散的一两段」变成**可核对前提、可照抄步骤**的条目。

**能减少常驻上下文的只有一处**：`AGENTS.md` §5 交付路径（78 行）。
但把它迁出 = **改规则源** = 元架构变更 ⇒ 按 `docs/commit-guidelines.md` 第 3 条
**必须先获用户明确授权**。**本次不做，提 issue 待裁**（见第四节）。
